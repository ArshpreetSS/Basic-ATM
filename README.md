# Basic-ATM
This is a simple Python-based ATM simulation mini-project that performs basic banking operations.

## Features
- Deposit Money
- Withdraw Money
- Display Balance
- View Transaction Statement
- Exit System

## Project Files
- `main.py` → Main menu and program execution
- `utils.py` → Stores balance and transaction records
- `deposit.py` → Handles deposit functionality
- `withdraw.py` → Handles withdrawal functionality
- `display_balance.py` → Shows current balance
- `statement.py` → Displays transaction history

## How to Run
1. Make sure Python is installed on your system.
2. Open the project folder in VS Code or terminal.
3. Run the following command:

```bash
python main.py
